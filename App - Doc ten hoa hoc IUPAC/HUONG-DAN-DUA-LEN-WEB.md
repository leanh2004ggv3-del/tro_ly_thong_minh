# ĐƯA APP LÊN WEB          ✅ BẢN NHÁP — nhờ GV Hoá soát trước khi đưa lên

**Thư mục tải lên:** `hoa-hoc/` (gồm `index.html` + thư mục `am/` có 696 tệp tiếng, khoảng 5 MB).
Phải giữ nguyên cấu trúc: `am/` nằm **cạnh** `index.html`, không thì loa không kêu.

## Cách 1 — GitHub trên trình duyệt (trang tro_ly_thong_minh của sếp)
1. Mở kho `tro_ly_thong_minh` → **Add file → Upload files**.
2. Kéo **cả thư mục `hoa-hoc`** từ máy vào (kéo thư mục, không kéo từng tệp) → **Commit changes**.
3. Đợi 1–2 phút, mở: `https://<tên-tài-khoản>.github.io/tro_ly_thong_minh/hoa-hoc/`
4. Muốn có nút trên trang chủ: thêm một liên kết tới `hoa-hoc/` trong menu.

## Cách 2 — dùng không cần mạng
Chép cả thư mục `hoa-hoc` vào USB/máy lớp → mở `index.html` bằng Chrome hoặc Edge.

## Sửa nội dung
Sửa `_cong-cu/src/ten.js` (tên, phiên âm, danh sách chất) hoặc `_cong-cu/src/app.html` (giao diện) → chạy:
`python _cong-cu/dung.py` (thu thêm tiếng cho tên mới — cần mạng; chỉ gửi tên hoá học) → tải lại thư mục `hoa-hoc/`.
